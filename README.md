=========Jawaban Soal Praktikum==========

#### 1. Apa fungsi `<table>`, `<tr>`, `<th>`, dan `<td>`?
**Jawaban:**  
`<table>` untuk bikin tabel.`<tr>` untuk baris.`<th>` untuk judul kolom/baris.`<td>` untuk isi data.  

#### 2. Apa perbedaan `<th>` dan `<td>`?  
**Jawaban:**  
`<th>` dipakai buat header (biasanya bold & tengah), sedangkan `<td>` buat isi biasa.  

#### 3. Apa fungsi `colspan` pada tabel?  
**Jawaban:**  
Menggabungkan beberapa kolom jadi satu sel.  

#### 4. Apa fungsi `<form>` dalam HTML?  
**Jawaban:**  
Tempat mengumpulkan input supaya bisa dikirim ke server.  

#### 5. Apa perbedaan radio button dan checkbox?  
**Jawaban:**  
- Radio button → pilih satu saja.Checkbox → bisa pilih banyak.  

#### 6. Mengapa `<label>` sebaiknya terhubung dengan `id` input lewat `for`?  
**Jawaban:**  
Supaya klik label langsung aktifin input, lebih ramah pengguna.  

#### 7. Apa perbedaan `<textarea>` dengan `input type="text"`?  
**Jawaban:**  
`<textarea>` buat teks panjang (multi-baris), sedangkan `text` cuma satu baris.  

#### 8. Apa fungsi semantic HTML seperti `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>`?  
**Jawaban:**  
Kasih struktur dan makna ke halaman, bikin lebih jelas buat SEO dan aksesibilitas.  

#### 9. Apa fungsi `required`, `min`, `max`, dan `minlength`?  
**Jawaban:**  
`required` → wajib diisi.`min` / `max` → batas angka.  `minlength` → minimal karakter.  

#### 10. Apa perbedaan `<audio>` dan `<video>`?  
**Jawaban:**  
`<audio>` buat suara, `<video>` buat video (bisa ada suara juga).
